### 🖥️ Windows 桌面版特性 (v1.1.6)

- **原生 C# + WPF 架构**：纯原生 Windows 桌面界面，启动迅速，交互流畅无卡顿。
- **论文 5 步全流程管线**：
  1. 📋 **任务书生成**：自动提炼研究背景、研究目标、技术路线与时间进度；
  2. 📖 **开题报告撰写**：包含研究意义、国内外现状、研究方案与预期成果；
  3. 📚 **文献综述推演**：学术观点对比、研究空白分析与理论支撑；
  4. 📝 **论文正文连贯写作**：引言、相关工作、实验设计、结果分析与结论总结；
  5. 🎤 **答辩PPT大纲**：讲稿要点与汇报大纲同步输出。
- **单文件绿色免安装**：已打包独立 Self-contained 运行环境，解压即运行，无需预装运行时。
- **本地 OpenXML 排版引擎**：一键导出为标准的微软 Office Word (`.docx`) 文档。

### 📱 Android 移动版特性 (v1.1.8)

- 🧠 **学术大纲智能推理**：输入题目即可生成多级规范大纲。
- 📖 **长篇章节流式生成**：克服 Token 截断，保障长文学术连贯性。
- 🎯 **字数精准约束机制**：稳定控制在目标设定值 1.0 ~ 1.2 倍之间。
- 📑 **标准 Docx 排版导出**：导出规范 Word 示例文档，正文四号字、无冗余样式。
- 🔋 **后台持续保活机制**：锁屏、切后台不中断论文推演。
- 🔄 **自动检测版本更新**：启动自动比对更新，支持一键升级。
